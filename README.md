# CS Brewed — Portfolio Landing Page

The official homepage for **CS Brewed** ([csbrewed.com](https://csbrewed.com)), the indie Apple development studio by **Serhii Chornonoh**.

## Products Featured
- **Teeth — Dental Journal**: iOS personal dental health journal & timeline ([teeth.csbrewed.com](https://teeth.csbrewed.com))
- **The Surf Hero**: macOS menu bar default browser switcher ([the-surf-hero.csbrewed.com](https://the-surf-hero.csbrewed.com))
- **Perespiv**: iOS & watchOS reverse singing party game ([App Store](https://apps.apple.com/ua/app/perespiv/id6738500826))

## Tech Stack
- Pure semantic HTML5 + Modern CSS (Light Theme)
- Responsive layout with desktop & mobile optimizations
- Zero external dependencies or analytics trackers (privacy-first)
- GitHub Pages ready (`CNAME`, `.nojekyll`, `robots.txt`, `sitemap.xml`)

## Quick Preview Locally
Open `index.html` in any browser or run:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
